# Hisab — Project Guide

POS, inventory, supplier, and reporting app for a Bangladeshi computer accessories/servicing shop.
**Stack:** React 19 + TypeScript + Vite | Cloudflare Worker + D1. Setup: [README.md](README.md), [deployment.md](deployment.md).

## UI & Architecture Rules
Derived from `src/*.css`, `src/i18n.ts`, `src/Receipt.tsx`, `worker/`, and `README.md`.

1. **Counter-First & Keyboard-Driven:** Prioritize cashier speed over decoration. Keep sale steps linear (`Choose item → Set price & quantity → Take payment`). Support full keyboard flows with `<kbd>` hints on primary actions: `F2` search, `↑/↓` navigate, `Enter` confirm, `+` payment, `Alt+B`/`Alt+C`, `Esc` close dialog, `?` shortcuts.
2. **Dense Ledger Layout:** Warm paper palette (`--paper #e9e7de`, `--white #fcfcfa`, ink `#22231f`) with hairline borders (`--line`, `--card-border`); no heavy shadows or gradients. Reuse density tokens in `styles.css` (`--workspace-gutter`, `--panel-inset`, `--row-height: 60px`, `--body-size: 14px`, `--detail-size: 11px`). Structure: fixed slim sidebar, topbar, page heading (eyebrow + tight-tracked title), 52px panel headers, uppercase table heads, workspace footer. Typography: `IBM Plex Mono` for numbers/bills/codes; `DM Sans Variable` for body.
3. **Color & Status:** Single green accent (`--accent #00853E`, `--accent-ink`, `--accent-selected`) strictly for primary actions, focus, and selection. Use semantic soft/border triplets (success, warning/amber, danger/red) from [src/theme.css](src/theme.css)—never hard-code colors. Use solid green/red toasts with left accent borders; offer Undo on destructive actions where possible.
4. **Light & Dark Parity:** All colors use CSS variables (`:root[data-theme="dark"]` / `.dark`: grays `#1e1e20–#2d2d30`, mint `#78d99e`), applied pre-paint via `public/theme-init.js`. Verify all UI in both themes. Receipts and PDFs stay locked to their fixed paper palette.
5. **Accessibility:** Require visible `:focus-visible` (`--focus`), compliant contrast (`--text-secondary`), native `<dialog>` modals (focus trap, inert background), skip link, `sr-only` labels, `forced-colors` support, and nav `aria-*`. Gate all animations inside `@media (prefers-reduced-motion: no-preference)`.
6. **Restrained Motion:** Short action feedback only (focus sweep, row flash, value bump, status pulse, subtle translate) via [src/motion.css](src/motion.css). Tokens `--dur-instant`/`--dur-fast`/`--dur-normal` (100/160/220ms) and `--ease-out-snappy`/`--ease-in-out-crisp` live in [src/styles.css](src/styles.css); legacy `--motion-fast`/`--motion-standard`/`--motion-ease` alias them. Micro-interactions animate `transform`/`opacity` only and are gated inside `@media (prefers-reduced-motion: no-preference)`. No layout shift or permanent `will-change`.
7. **Bilingual (EN + BN):** Store all copy in [src/i18n.ts](src/i18n.ts), `reportsCopy.ts`, and `suppliersCopy.ts`—never hard-code strings. Bangla uses `Noto Sans Bengali Variable` with normal spacing/kerning (`.lang-bn`); layouts must accommodate longer BN text. Use plain shopkeeper terms ("Counter", "Stock", "Customers", "Take payment") over accounting jargon. Format currency in whole Taka (`৳`) and dates in `Asia/Dhaka`.
8. **Honest Feedback:** Await backend confirmation before showing success. Surface failures, stale revisions, and interrupted responses explicitly for review before retry. Mark uncertain historical data as unavailable rather than guessing. Show live connection status ("Connected" / "Connection issue"). Require confirmation/reasons for destructive actions (void, return, archive instead of delete).
9. **Responsive (Desktop-First):** Breakpoints at `1600`, `1200`, `900`, and `680px` (sidebar scales `88 → 72 → 54px`) plus compact mode at height `≤800px`. Keep mobile usable.
10. **Print & Brand Identity:** A4 cash memo ([src/receipt.css](src/receipt.css), `ReceiptArt.tsx`) uses a strict `210×297mm` grid, green/navy palette, `Russo One` title, payment logos (bKash, Nagad, Rocket), and equipment art—verify any edits against print/PDF previews (`output/`). Exports (PDF, CSV/JSON, spreadsheets) share branding (`reportBrand.ts`, `reportPdf*.ts`).
11. **Conventions:** Plain CSS per domain (`styles.css`, `theme.css`, `motion.css`, `navigation.css`, `reports.css`, `suppliers.css`, `login.css`, `receipt.css`, `web-accessibility.css`); extend existing tokens/classes without UI libraries. Use inline SVGs ([src/Icons.tsx](src/Icons.tsx)) and self-hosted `@fontsource` fonts only (no CDN/external assets; strict CSP in `public/_headers`). Run/add tests (`npm test`, `test:pricing-ui`, `test:web-ui`) when touching money, receipts, or core flows.
